# NCorrelation 
Communicating nonlocal correlations project, done during the first cohort of the Global Guided Research Project (GGRP) by QUAE (part of QWorld). </br>

This repository consist of 3 python classes (Classic_Teleportation.py, Max_Entanglement.py and Weak_Entanglement) that aims to simulate three protocols present on the paper [The minimal communication cost for simulating entangled qubits](https://arxiv.org/abs/2207.12457), the main file (main.py) that imports them to do the simulation, and a plotter (plotter.gp).
